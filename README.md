# Open-QS-project
School project

algo: construct unitaries for non-unitary operators and SVD; prepare Sz.-Nagy algorithms  
metric: do tomography, compute fidelity, forbenius distance and success probability    
noise: simulate possible noises for quantum circuit  
plot: prepare bloch trajectory plot, coherence & populations plot, and noise resilience plot  
subnorm: simulate preparation of subnormalised state and test noise resilience of different algos (execution)  
timeevo: simulate non-unitary time evolution for ZZ and amplitude damping channels and test noise resilience of different algos (execution)
